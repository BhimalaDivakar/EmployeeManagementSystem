# Employee Management System

A full-stack Employee Management System built using React, Spring Boot, Java, and MySQL.

## Features

- Admin Login
- Dashboard
- Add Employee
- View Employee List
- Search Employees
- Filter Employees by Department
- Edit Employee
- Delete Employee
- Delete Confirmation
- Export Employee Data to CSV
- Employee Statistics
- Department Charts
- Total Salary Calculation
- Average Salary Calculation
- Responsive User Interface

## Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- Bootstrap
- Axios
- React Router
- Chart.js

### Backend
- Java
- Spring Boot
- REST API
- Maven

### Database
- MySQL
